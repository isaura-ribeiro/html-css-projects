O que é o Método do Mapa e Como Funciona?

Transcrição

O que é o Método Mapa e como Funciona? O Método Mapa é uma função poderosa e muito utilizada em JavaScript, que opera sobre arrays. É desenhado para criar um novo array ao aplicar a função dada a cada elemento do array original. Este método não altera o array original, e em vez disso retorna um novo array, que contém os resultados da função aplicada a cada elemento. Aqui está um exemplo de usar o método mapa num array de números. Para criar um novo array, onde cada número é o seu dobro, vamos usar o método map. O método mapa aceita uma função callback, onde a função é chamada em cada um dos elementos do array. Neste caso, cada elemento do array será multiplicado por 2. O resultado será um novo array dos números 2, 4, 6, 8, 10. A função callback pode aceitar até 3 argumentos. O primeiro argumento é o elemento atualmente processado. O segundo argumento é o índice do atual elemento processado. O terceiro argumento é o array onde o método mapa está a ser chamado. Perceber e utilizar de forma eficiente o método mapa pode melhorar de forma significativa a tua capacidade de trabalhar com arrays em JavaScript.
